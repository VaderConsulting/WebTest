# WebTest

VB.NET Visual Studio 2005 ASMX web service that records computer status rows into a Jet/Access database for Empired-style status tracking. `Service1.InsertStatus` opens `My.Settings.SQLConnectionString` and either reads `tblStatus` or inserts `(Computer, Status)` via OleDb (write is the active path). `WebTestConsole` is a command-line client that passes computer name and status as arguments to the remote service; `WebTestConsumer` is a WinForms shell that calls `InsertStatus` once on form load. Both clients use generated web references aimed at a local IIS host path `/webtest/service1.asmx`.

**Source last updated:** 2007-05-08 · **Language:** VB.NET · **Target:** .NET Framework 2.0 (VS 2005 / ProductVersion 8.0.50727) · **Output:** ASP.NET web application library (`WebTest` ASMX), console exe (`WebTestConsole`), WinForms exe (`WebTestConsumer`)

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `WebTest` (`WebTest/WebTest.vbproj`) | VB.NET | ASP.NET web application (`Library`, ASMX, net20) | Hosts `Service1.asmx`; `InsertStatus` writes computer/status to Jet `tblStatus`. |
| `WebTestConsole` (`WebTestConsole/WebTestConsole.vbproj`) | VB.NET | Console exe (`Exe`, net20) | CLI client; args = computer name + status; calls remote `Service1.InsertStatus`. |
| `WebTestConsumer` (`WebTestConsumer/WebTestConsumer.vbproj`) | VB.NET | WinForms exe (`WinExe`, net20) | Minimal form; on load calls `InsertStatus` with a sample computer name. |

## How to open

Open `WebTest.sln` in Visual Studio 2005 or later (solution format 9.00). Copy each `*.example` file to the matching name without `.example` (web.config, app.config, Settings.*, and web-reference disco/wsdl/map files) and point the SQL connection string and service URL at your own Access database and ASMX host. `WebTest` uses the VS development server on an auto-assigned port (project default 53557). Requires .NET Framework 2.0 and Jet OLEDB for the Access backend. `App_Data` ASP.NET membership database files are not included.
